## 练 1 · 认写法（口头，1 分钟，全班一起答）

判断下面四段各自属于哪种写法，谁会因为「换个地方运行」而失效：

```python
A. PORT = 8080
B. LOG = open(r"D:\web\log.txt", "a", encoding="utf-8")
C. LOG = open("logs/app.log", "a", encoding="utf-8")
D. LOG = open(Path(__file__).resolve().parent / "logs" / "app.log", "a", encoding="utf-8")
```

答案：A 硬编码值（端口写死，换环境要改源码）；B 写死绝对路径（没有 D 盘或没有该目录就 `OSError`）；
C 相对路径（cwd 不是项目根时 `FileNotFoundError`）；D pathlib，能打包。
批改标准：判断对类型 + 能说出「在哪一步炸」。

## 练 3 · 换个系统（思考题，课后）

同一段代码要搬到欧拉（openEuler）的 `/home/student/pythonProject/` 下，哪些要改？

答案：什么都不用改。`pathlib` 自动处理分隔符；不要出现 `"\\"` 手工拼接、不要出现盘符即可。
如果代码里有 `os.path.join` 再拼字符串，也没问题，但 `BASE / "data" / "a.txt"` 更好读。

## 常见错法对照（讲评时用）

| 学生常写 | 问题 | 改成 |
|---|---|---|
| `open("data/a.txt")` 就交 | 从 IDE 运行可以，从别处启动就炸 | `BASE / "data" / "a.txt"` |
| `os.chdir(os.path.dirname(__file__))` 忘了 `resolve` | 相对解释器路径下 `__file__` 可能是相对值 | `os.chdir(Path(__file__).resolve().parent)` |
| 用 `sys.path[0]` 当项目根 | 打包成 exe 后 `sys.path[0]` 不可靠 | 用 `__file__`（或 `sys._MEIPASS` 兜底） |
| 把 `config.json` 路径也写死 | 配置本身就成了硬编码 | 配置路径同样用 `BASE / "config.json"` |
